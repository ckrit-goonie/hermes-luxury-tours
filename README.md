# Hermes Luxury Tours Landing Page

This starter package includes:

- `index.html`
- `style.css`
- `script.js`

## Before launching

1. Replace the demo phone number, service area, and email if needed.
2. Replace the sample tours and destination photographs.
3. Connect the contact form to Formspree, HubSpot, Mailchimp, GoDaddy, WordPress, or a custom backend.
4. Add a privacy policy and terms page.
5. Confirm that the name and logo do not conflict with third-party trademarks.
6. Upload the files to your web host and point HermesLuxuryTours.com to the hosting account.

The images currently load from Unsplash and the fonts load from Google Fonts, so an internet connection is required.
